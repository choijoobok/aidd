# S08 — 통합 진행 기록

APR-006으로 승인된 S08 구현·자동 검증을 완료했다. 실제 provider 행동 평가는 not_run으로 분리한다. S09 변환/구형 writer 제거, S10 전체 인수, 실제 프로젝트·커밋·릴리스는 범위 밖이다.

## 해결할 실패와 작업

1. S03의 367개 자산 분류를 현재 파일과 대조하고 처리/보존/S09 인계 여부를 기록한다. 승인된 S02/S03 파일은 불변이다.
2. 전역 파일·단일 phase·무조건 초기화/전체 검사·옛 옵션을 가리키는 스킬/참조/가이드/템플릿을 v2 절차로 정합화한다. 스킬/훅의 역할과 공개 경계는 유지한다.
3. v2의 용어·이력·가정·병합·평가·문서 영향·초기화 전문 명령을 일반 저장/조회/트랜잭션에 연결한다. 실제 Git/사용자 결정/평가 증거를 발명하지 않는다.
4. DG/TG 기존 의미와 새 준비도 매핑을 대조하고 의미가 바뀐 ID를 바로잡는다. 배포/기술 검토를 요구 필드 검사나 릴리스 검사로 대체하지 않는다.
5. 독립 훅, 두 provider 복사본, 정상/실패 수행 흐름과 범위 격리를 검증한다. 실제 provider 평가가 실행되지 않으면 파일 동일성/fixture 통과와 분리해 not_run으로 남긴다.

## 검증·호환성·롤백

전문 명령·현재 입력/실제 증거·저장 충돌·모듈 격리의 행위 회귀, sync-providers/check, hook self-test, smoke와 승인본 해시·UTF-8/LF/링크를 확인한다. major 개편 안의 보완이며 기존 이력이나 사용자 수정은 지우지 않는다. 변경은 소유 코드/지침과 검증 기록으로 식별하고 필요한 증분만 되돌릴 수 있게 한다. 신규 런타임 훅/플러그인/스킬은 만들지 않는다.

## 완료 결과

- [통합 지도](../integration/README.md): S03 367개를 10개 파일로 전수 대응. 208개 유지, 100개 수정·재생성, 59개 S09 잔여. 유지와 미완료 전환을 구분한다.
- portable 17개 스킬·참조·팀 가이드·방법론·워크시트·export 수행 계약을 검토했다. 전역 OI/DRQ/TRM/HIS 경로, FEAT 미채택 설명, 상태 조회의 자동 초기화를 수정했다. 관리 스킬은 기존 경계를 유지한다. provider 복사본은 공식 명령으로 재생성했다.
- 전문 CLI의 용어/가정/이력/병합/평가/문서 영향·staged 검사·초기화 안내를 v2에 연결했다. 전역 legacy writer로 우회하지 않는다. operation 재시도·기대 해시·불변 TCH/EVR/HIS를 유지한다.
- DG/TG의 잘못된 의미 매핑을 복원하고 RL-001을 분리했다. 릴리스는 주기/작업별 현재 게이트 입력을 따로 대조한다. 이는 S03에서 보존하기로 한 기존 게이트 의미의 복원이며 새로운 업무 결정의 대리 승인이 아니다.
- 가정 무효화는 후속 영향 OI, 필수 병합 테스트는 MRC, 실제 provider 평가는 EVS/EVD/EVR로 연결한다. 미실행·stale를 passed로 승격하지 않는다.
- DRQ 묶음·우선순위·공통 질문·병합 재검토와 선행 업무 분석을 브리핑에 연결했다. DEP/ARC 등 명시적 의존 필드도 영향 그래프에 포함한다.
- Codex 독립 후처리의 Windows 경로 정규화 보완. runtime 훅의 수·명령·등록 슬롯과 다른 훅 격리는 유지한다. 제품 Git post-merge에는 재시도 operation을 전달한다.
- 공통 용어 AIDD-TERM-042와 CLI 해시 잠금을 채택된 FEAT 의미로 갱신했다. legacy fixture 생성물은 생성기로만 재생성했다. 실제 제품 정본이 아니다.

## 한계·다음 승인

전문 명령의 전역 용어 중복·병합·평가 검사는 보수적인 scanAll을 사용한다. 모든 명령의 소규모 조회 최적화를 보증하지 않는다. 명세의 의미적 충분성·실제 사용자 수용은 자동 검사 통과와 별도다. 협력 writer/로컬 파일시스템 경계를 유지한다.

다음 S09는 새 프로젝트·export·v2 기준 fixture·명시적 v1 후보 변환/롤백·구형 공개 writer 격리다. 원본을 덮어쓰거나 사용자의 실제 프로젝트를 자동 변환하지 않는다. **사용자 승인 전 S09에 착수하지 않는다.** 현재 버전 1.0.0, KIT-CHG-018 major/in_progress 유지. 커밋·태그·릴리스 없음.
