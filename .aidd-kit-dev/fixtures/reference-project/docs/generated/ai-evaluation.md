- **id:** EVP-001
- **title:** Codex·Claude 공통 행동 평가 정책
- **platforms:** codex, claude
- **rule:** 두 플랫폼에 같은 정본, 픽스처와 루브릭을 제공하고 플랫폼별 결과와 증거를 독립적으로 기록한다. 파일 동등성만으로 행동 동등성을 주장하지 않는다.
