# KIT-REQ-018-017 — 항목별 문서·매뉴얼·제출물 생성

- 출처: 사용자 파생 문서·작은 파일·인덱스 요청 / 계획 목표 10, 12~13
- 목적: 정본 분리 이후에도 독자별로 찾기 쉽고 재현 가능한 문서를 제공한다.
- 대상·트리거: 설계 문서·사용자 가이드·운영 문서·DLP 제출물의 생성·갱신.

## 요구 동작

- 프로젝트/모듈 진입 문서는 요약과 탐색을 제공하고 상세 기능·화면·데이터·절차는 의미 단위로 분리한다. 항목의 정본과 관련 상세 문서로 이동할 수 있어야 한다.
- 정본에서 상태·본문·연결을 생성한다. 생성 Markdown/HTML을 직접 수정해 정본을 대체하지 않는다. 사용자 가이드는 실제 사용자 절차·조건·예외를 설명한다.
- 설계 목업·검증된 실제 화면·운영 지침을 구분한다. 제출 범위·입력 기준선·생성 조건을 식별하고 독자 및 DLP 포함 정책을 적용한다.
- 동일 입력의 전체 재생성 결과에서 파일 목록과 내용을 비교한다. 과거 생성물의 잔재와 새 항목 누락을 함께 찾는다.
- 범위별 생성은 그 범위가 소유한 출력만 갱신·정리한다. 다른 모듈 문서나 사용자 작성 파일을 삭제하지 않는다. 링크와 필요한 오프라인 탐색을 검증한다.

## 범위·관계

- 포함: 현재 Kit이 제공하는 설계·사용자·운영·제출 산출물의 새 구조 대응.
- 제외: 새로운 문서 플랫폼·호스팅·배포 서비스를 필수로 추가하거나 생성 결과를 별도 정본으로 운영하는 것.
- 관계: 005, 008~009, 012, 014~016, 018~019.

## 인수 기준

- AC-017-1: 여러 기능·화면의 상세가 탐색 가능한 별도 문서로 생성되고 정본 및 관련 문서 링크가 유효하다.
- AC-017-2: 최신 정본 전체 재생성과 비교해 누락·낡은 내용·불필요한 과거 출력이 검출된다.
- AC-017-3: A 범위 재생성이 B 및 사용자 파일을 보존하며 제출물의 기준선·DLP·목업/실제 증거 구분을 확인할 수 있다.
- 검증 연결: ACC-017.
