# AI 주도 개발·운영 프레임워크 — 프로젝트 개요

## 비전

고객과 여러 역할을 수행하는 AI가 일관되고 감사 가능한 정본을 바탕으로 소프트웨어를 계획·개발·검증·출시·운영·개선하게 한다.

## 해결할 문제

AI 지원 프로젝트에서 요구사항, 설계, 코드, 테스트와 매뉴얼이 서로 무관한 서술형 산출물로 진화하면 의도와 일관성을 잃는다.

## 현재 수행 조건

- 단계: `기반 구축`
- 수행 방식: `신규 프레임워크 구축`
- 품질 프로필: `균형형`
- 고객 의사결정 책임자: 프로젝트 책임자

## 기대 성과

- **OUT-001** 변경을 고객 의도에서 설계, 구현, 검증, 출시와 운영까지 추적할 수 있다.  
  측정: 추적성 검증 오류 수 · 목표: 0
- **OUT-002** Codex와 Claude가 동일한 정본 작업 절차와 품질 규칙을 수행한다.  
  측정: 어댑터 불일치 발견 수 · 목표: 0
- **OUT-003** 의사결정자가 대화 기록을 재구성하지 않고 전체, 모듈과 항목 수준 상태를 확인할 수 있다.  
  측정: 현재 레코드에서 생성된 상태 뷰 · 목표: 경영진, 모듈과 상세 뷰 제공

## 포함 범위

- 생애주기 방법론과 거버넌스
- 상황 적응형 방법론 선택과 기술 스택·개발 기반 게이트
- 배포·운영 환경 프로필과 동시성·트랜잭션·성능 위험 예방
- 산출물 정본 모델과 자동 생성 문서
- 이식 가능한 AI 스킬과 네이티브 훅 어댑터
- 검증, 상태와 병합 영향 자동화
- 변경별 게이트 실행, 구조화된 증거, 승인과 예외 통제
- 활성 참여자 기반 1인·팀 협업 프로필과 가역적 전환
- Git·호스팅 신원과 사람 참여자·봇의 명시적 대조
- 신규 구축, 기존 시스템, 기능, 결함과 유지보수 흐름

## 제외 범위

- 호스팅형 프로젝트 관리 사용자 인터페이스
- 특정 공급자에 종속된 CI/CD 배포
- 포트폴리오 규모 집계를 위한 운영 데이터베이스
