## 호환성과 범위

신규 프로젝트는 `owned-records-v2`를 사용한다. 기존 AIDD 버전 전용 변환·자동 업그레이드·patch·merge·역동기화는 제공하지 않는다([KIT-ADR-011](../decisions/KIT-ADR-011.json)). 일반 레거시 소스·문서 역분석은 별도 기능으로 제공한다. 이전 v1 reference fixture는 기존 생성기 회귀 입력으로 유지한다.

현재 행동 명세는 [v2 정본](../../.ai/spec/owned-records-v2.md), [업무 분석](../../.ai/spec/business-discovery.md), [접속 정책](../../.ai/spec/system-access.md), [역분석](../../.ai/spec/reverse-engineering.md), [검토·재분석](../../.ai/spec/legacy-review-reanalysis.md), [도입·검증](../../.ai/spec/legacy-adoption.md), [전문 통합](../../.ai/spec/specialty-integration.md), [배포](../../.ai/spec/distribution-layout.md)에 있다. 설계 결정은 KIT-ADR-006~014를 따른다.

되돌릴 때는 개편 전 기준선 `7d645328bf9f9c2c9dd7ea5010a2d1859779966b`와 구현 커밋을 비교해 해당 변경을 선택적으로 복원한다. 생성된 v2 프로젝트의 데이터·사용자 수정·승인·검증·운영 이력에는 자동 downgrade를 적용하지 않는다.

## 완료 당시 검증

구현 커밋 기준 전체 자동 회귀 150/150, provider 동기화, Kit check·smoke, 훅 배선 self-test가 통과했다. 생성 문서 전체 비교, 폴더/ZIP 동등성, v2 신규 프로젝트, 혼합 SSOT 거부, 기존 출력 보호를 확인했다.

요구 21개·인수 기준 63개·시나리오 22개를 검토했다. 적용 요구 20개와 기준 60개는 verified이며, 이전 AIDD 전용 변환 요구 KIT-REQ-018-020과 기준 3개는 KIT-ADR-011로 철회(superseded)했다. 시나리오 검증은 자동 회귀의 조합이며 실제 고객 운영 인수를 뜻하지 않는다. 기존 자산 367개와 마지막 잔여 59개를 대응했고 당시 요구·설계 승인본의 해시를 보존했다.

150건은 완료 당시 수치다. 이후 KIT-CHG-019에서 과거 계획·승인본 자체를 확인하던 일회성 검사 2건을 종료했고, 실제 기능 회귀와 portable 스킬 연결 검사는 유지했다. 현재 검증은 현재 테스트 집합을 기준으로 한다.

## 알려진 한계

- 실제 고객 시스템 도입·운영 데이터 이관, 외부 Codex·Claude의 실제 프로젝트 수행, 브라우저별 시각·접근성 사용자 수용은 수행하지 않았다.
- 역분석은 모든 언어·Office·PDF의 의미를 자동 복원하는 파서가 아니다. 의미 판단과 사용자 검토는 AI·사용자가 수행한다.
- 문서 채택은 한 모듈 CHG 전체 단위다. 재분석의 전체 정본 해시 비교는 무관한 동시 수정에도 미리보기를 다시 요구할 수 있으며 중첩 필드·배열은 원자 값으로 비교한다.
- 로컬 파일시스템의 협력 writer 범위로 검증했다. 비협력 편집기·분산 파일시스템·전원 장애의 완전 원자성은 보증하지 않는다. 일부 전역 중복·병합·평가 검사는 전체 조회를 사용한다.
- 릴리스 준비·버전 갱신·태그·실제 배포는 이 구현 완료에 포함되지 않았다. 출시 여부는 JSON 변경 레코드의 `released_in`으로 확인한다.
