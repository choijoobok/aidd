# KIT-REQ-018-016 — 일관된 브리핑·다음 작업·세션 재개

- 출처: 사용자 진행 상황 브리핑·계정 전환 요청 / 계획 목표 8, 12~14
- 목적: 어떤 세션·출력에서도 같은 현재 상태와 다음 작업을 파악한다.
- 대상·트리거: 프로젝트/모듈/주기/항목 상태 요청, 중단·재개, 사용자 결정 요청.

## 요구 동작

- 브리핑·CLI·게이트·파생 문서는 같은 준비도와 유효성 판정에 기반한다. 문서에서 별도 상태를 추측하거나 대화만으로 완료를 선언하지 않는다.
- 운영 기준선과 활성 신규/변경 주기를 함께 표시한다. 정의·구현·검토 유효성, 차단 대상·원인, 미결 결정과 다음 행동을 구분한다.
- 진척 수치를 제공하면 모집단·범위·계산 근거를 밝힌다. 알 수 없음·미실행·실패·재검토 필요를 같은 미완료 값으로 숨기지 않는다.
- 범위별 브리핑은 관련 미결을 중심으로 보여 주되 프로젝트 전체 결정 큐의 존재와 조회 경로를 유지한다. 무관한 미결을 현재 작업의 차단으로 표시하지 않는다.
- 새 세션은 인덱스·현재 기준선·활성 작업·최신 검토/결정으로 재개할 수 있다. 승인 범위를 확대하지 않고 다음 가능한 작업을 제안한다. 읽기 전용 조회가 정본 상태를 자동 변경하지 않는다.

## 범위·관계

- 포함: 제품 수행 상태와 이번 Kit 개편 계획의 재개 가능성.
- 제외: 모든 프로젝트에 매 단계 사용자 착수 승인을 강제하는 것. 이번 계획의 단계별 승인은 사용자가 별도로 요청한 진행 정책이다.
- 관계: 006~009, 013~015, 017~018.

## 인수 기준

- AC-016-1: 동일 입력에 대한 CLI·브리핑·생성 문서의 현재 상태와 차단 이유가 일치한다.
- AC-016-2: A 운영/B 신규 분석 상태와 B의 다음 작업, 관련 결정 질문을 인덱스와 기록만으로 재구성한다.
- AC-016-3: 조회 후 정본 내용은 불변이고 근거 없는 완료율·대화 유래 승인·무관한 차단이 표시되지 않는다.
- 검증 연결: ACC-016.
