# 변경 정보 교환

Kit 원본과 프로젝트 사이에는 코드를 자동 전달하지 않고 변경 설명서를 공유한다. 설명서에는 최소한 다음 내용을 포함한다.

- 해결하려는 문제와 관찰된 실패
- 변경 의도와 적용하지 않는 범위
- 적용 환경, 선행 조건과 중요한 가정
- 영향을 받는 규칙·스킬·훅·도구·템플릿
- 구현 접근과 고려한 대안
- 검증 방법과 실제 결과
- 호환성·보안·운영 위험과 롤백 방법

수신 측은 설명서를 입력으로 자체 영향 분석과 승인 절차를 수행하고, 자신의 환경에 맞는 새 변경으로 구현한다. 원본 파일 동일성이나 패치 적용 성공을 의미적 적합성으로 간주하지 않는다.
