# 목적과 경계

AIDD Kit은 업무 시스템이나 애플리케이션 자체가 아니라, AI와 사람이 제품 개발을 일관되게 수행하도록 돕는 규칙·정본 모델·스킬·훅·도구·템플릿의 배포 가능한 실행 기반이다.

Kit의 책임은 다음과 같다.

- 제품 의도부터 운영까지 추적 가능한 프로젝트 수행 계약을 제공한다.
- 구조화된 제품 정본과 파생 문서를 생성·검증하는 도구를 제공한다.
- Codex와 Claude가 공통 정책을 따르도록 이식 가능한 스킬과 훅 계약을 제공한다.
- 새 프로젝트가 독립적으로 수정·확장할 수 있는 시작 스냅샷을 제공한다.

Kit의 책임이 아닌 것은 다음과 같다.

- 배포된 프로젝트의 규칙·스킬·훅을 원본과 영구히 같게 유지하는 것
- 배포된 프로젝트에 원본 변경을 자동 병합하거나 패치하는 것
- 프로젝트 변경을 원본 Kit에 자동 역반영하는 것
- 프로젝트의 제품 정본을 Kit 원본 저장소에서 관리하는 것

Kit 원본과 각 프로젝트는 export 시점 이후 독립적인 변경 계보를 가진다.
