# AIDD Kit 0.2.0 기준선

기준일: 2026-09-20
포함 변경: `KIT-CHG-001`

## 현재 기준

- `aidd-requirement-verification` 스킬이 사용자 요청 범위의 AIDD 요건 구현을 검증한다.
- 일상 검증은 `kit.mjs check`와 변경 영역의 작은 행위 테스트를 사용한다.
- 생성기·fixture·export·new-project·provider 경계 변경에만 `kit.mjs smoke`를 사용한다.
- 파생 문서는 현재 정본에서 다시 만든 기대 파일 목록과 전체 내용을 비교한다.
- 명세 밖 보안·권한·신원·서명 검사는 사용자가 요청하지 않으면 수행하지 않는다.
- 과거 `KIT-EVD`, 변경·결정 상세 기록은 현재 기준선에서 제거했으며 Git 이력으로 조회한다.

## 배포 경계

- directory와 ZIP은 같은 export 허용 목록과 staging 검증을 사용한다.
- `.aidd-kit-dev/`와 관리 전용 스킬은 배포물에 포함하지 않는다.
- 자동 업그레이드와 프로젝트→원본 역동기화는 제공하지 않는다.

## 롤백

문제가 있으면 이 기준선 변경을 되돌려 이전 검증 구조를 복원한다.
