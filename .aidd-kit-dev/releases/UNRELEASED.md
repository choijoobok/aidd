- reference fixture의 일상 검증 문구를 전체 Node 테스트 강제에서 변경 영역 테스트로 현행화했다.

- 프로젝트 용어 관리를 PM의 영향 브리핑 확인 뒤 AI가 현재 `TRM`·`TCH` 이력, 관련 문서·소스 주석 현행화, 파생 문서 생성과 검증을 한 흐름으로 완료하도록 단순화하고 팀원 제안·`TIR`·`TAP`·반려·위임 상태를 제거했다.
- 요구분석·설계 중 AI가 새롭거나 모호한 용어를 발견하면 PM에게 정의·분류·범위·혼동 구분을 확인하고, 확인 직후 관련 정본과 용어집을 자동 현행화하도록 용어 구조·스킬·작업 서식·생성 문서를 강화했다.
