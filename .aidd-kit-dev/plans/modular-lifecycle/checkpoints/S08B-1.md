# S08B-1 — 일반 레거시 자료·근거·정본 초안 핵심 완료

APR-010으로 요구안 개정 1을 수용하고 첫 단계만 구현했다. [portable 계약](../../../../.ai/spec/reverse-engineering.md), [사용 안내](../../../../.ai/docs/guides/legacy-reverse-workflow.md), KIT-ADR-012가 현재 구현을 설명한다. 이전 AIDD 형식 변환 제외는 유지한다.

## 구현 결과

- `legacy-inventory`: Git 없는 다중 루트·해시·행수·선언된 revision·제외·링크·미지원·읽기 실패·수집 상한을 기록한다. 원본 실행/수정/이동·외부 전송 없이 동작한다.
- `legacy-draft`: AI/도구의 구조화 관측과 출처 해시·행을 검증하고 MOD/SYS/CAP/ACT/POL/UC/BPR/REQ/NFR/FEAT/SCR/DAT/NAV/IFC 뼈대를 생성한다. 출처 확인은 의미의 참/실행 증명이 아니다.
- observed/inferred/unknown·다중 출처 충돌을 구분한다. 불확실한 값은 관측에 보존하고 정본에 known으로 승격하지 않는다. 인증 부재를 공개 정책으로 추측하지 않는다.
- LDP 배치 요약·25항목 단위 DOC 자료 목록·관측별 SURF·후보별 DOC 근거 대응·검토 OI를 작은 정본으로 연결한다. 레코드별 32KiB 상한, 안정 ID와 기존 계층 인덱스/문서 생성 사용.
- `legacy-apply`: 미리보기 재구성·출처 재확인·관련 기존 입력 CAS·생성 전용 transaction. 기존 정본이 다르면 중단하고 편집/승인을 보존한다. 동일 입력 no-op, 동일 operation 과거 결과 replay, prepared 명시 복구 지원. 무관한 모듈 수정은 CAS 대상에서 제외한다.
- 생성 직후 사용자 승인/실제 실행/릴리스는 없고 일반 게이트는 blocked다. 관측은 SURF의 analysis 투영에 두어 후속 검토 입력 변경을 감지한다. 재분석의 자동 검토 묶음/병합/영향 분류는 아직 구현하지 않았다.
- 기존 레거시 스킬과 참조, public manifest/spec index, 두 독자 가이드와 provider 복사본을 연결했다. 새 스킬·플러그인·runtime 훅 없음. export 허용 목록은 기존 .ai 항목을 사용하며 관리 자료는 배포하지 않는다.

## 한계·롤백·다음 승인

테스트는 임시 fixture다. 실제 고객 소스·PDF/Office 추출·스택별 파서·제품 동작 검증·외부 provider 수행은 not_run이다. UTF-8 수집과 AI 구조화 관측을 연결하는 기능이지 모든 소스에서 업무 의미를 단독 추출하는 만능 파서가 아니다.

현재 apply는 새 CHG/초안 생성 전용이다. 기존 정본 변경/삭제/재분석 3-way 병합, 검토 묶음 자동화, project/src 외 staged 영향, 모듈별 도입 준비도는 S08B-2/3에서 진행한다. 최초 구조 검사는 scanAll을 사용하므로 무관한 깨진 정본도 적용 전 보수가 필요할 수 있다. source scan과 정본 commit 사이 비협력 외부 writer·분산 FS의 원자성은 보장하지 않는다. scope_complete는 열거 범위, semantic_complete=false는 아직 업무 분석 완료가 아님을 뜻한다.

명령을 사용하지 않으면 자동 실행은 없다. 미완료 transaction은 기존 복구 명령으로 처리한다. 적용 완료 초안은 operation 경로/snapshot을 확인하고 후속 사용자 편집·검토를 보존하는 정상 변경으로 정리한다. 원본이나 승인 이력을 일괄 삭제하지 않는다.

전체 KIT-CHG-018은 major/in_progress, 버전 1.0.0 유지. 실제 제품 도입·커밋·태그·릴리스 없음. 다음 KIT-DRQ-018-07에서 S08B-2 사용자 검토 묶음·재분석 충돌/영향 통합의 승인을 요청한다. S08B-3와 S09/S10은 아직 시작하지 않는다.
