# S08B-2 — 순차 사용자 검토·재분석·영향 연결 완료

APR-011은 S08B-2만 승인했다. [portable 계약](../../../../.ai/spec/legacy-review-reanalysis.md), [사용 안내](../../../../.ai/docs/guides/legacy-reverse-workflow.md), KIT-ADR-013을 따른다. S08B 제출본 3개와 S02/S03 승인본은 변경하지 않았다. 현재 단계와 다음 승인은 [status.json](../status.json)에 기록한다.

## 구현 결과

- `legacy-review`: 시스템/핵심 업무·모듈 → 역할/접속 정책 → UC/프로세스 → 요구 → 설계의 순차 묶음. 최대 3개 항목에 현재 정의·근거·미정·상세 오류·검토 유효성을 함께 표시한다. 미완성 앞단을 건너뛰지 않는다.
- `legacy-review-request/answer`: OI를 먼저 연결한 DRQ, 실제 제시 시각과 사용자 결정 출처, 항목별 RVW/HIS. 일부만 답변·보류·보완·거절할 수 있고 오래된 답변은 이력만 남긴다. 상세 미완성 항목을 수용해도 OI가 닫히거나 다음 단계가 열리지 않는다. 사용자 답변만으로 정의를 자동 수정하거나 범위/일관성/기준선/목업 승인을 대신하지 않는다.
- `legacy-reanalyze/reconcile`: 이전 기계 생성본·현재 정본·새 제안의 세 버전 비교. 사용자 단독 수정, 출처 단독 수정, 동일 변경과 충돌을 구별한다. 명시 선택·이유·사용자 판단을 받은 변경만 CAS/transaction으로 반영한다. 생성 기준을 후보별 작은 DOC에 따로 보존하고 영수증과 불변 HIS로 연결한다.
- 파일 이동 후보·누락·부분 스캔·hash/revision 변경을 구분한다. 관측 부재로 정본을 삭제/폐기하거나 CHG 범위를 축소하지 않는다. 실행 상태·승인·운영 이력과 무관한 모듈 작업을 보존한다.
- 변경된 정의/근거 입력에 검토 OI와 pending IMP를 생성하며 기존 impactGraph의 직접/간접 경로를 사용한다. 실제 작업 재개는 기존 impact-apply의 명시 판단을 따른다.
- `legacy-source-check`: Git 없는 외부 루트도 읽기 전용 재수집/영향 확인. 저장소 안에 선언된 project/src 외 루트는 staged 검사에 포함하고 index/작업 트리 차이를 차단한다. 저장소 밖 루트의 미검사 경계는 숨기지 않는다.
- 브리핑과 파생 문서는 동일 legacy review 모델을 사용한다. legacy/status 스킬·가이드·명세/public manifest와 provider 복사본을 맞췄다. 새 runtime 훅·스킬·플러그인은 없고 기존 export 허용 목록을 재사용한다.

## 한계·롤백·다음 승인

현재 세 버전 비교는 title·관계·definition 최상위 필드 단위다. 배열/중첩 값은 한 필드이므로 복잡한 충돌은 사람이 결합한 정상 record-put 뒤 재검토해야 한다. 의미적 모순 검토나 사용자 판단을 기계 비교로 대신하지 않는다. 재분석은 전체 정본 read set을 보수적으로 고정하여 무관한 동시 수정에도 미리보기가 다시 필요할 수 있다. source scan과 정본 commit 사이 비협력 외부 writer·분산 FS의 완전 원자성은 보장하지 않는다.

기존 legacy-apply는 생성 전용으로 유지한다. 신규 명령은 명시 실행할 때만 동작한다. 실패한 transaction은 기존 status/recover로 처리하고 동일 operation은 과거 결과를 재사용한다. 완료된 적용을 되돌릴 때는 snapshot·영수증과 후속 편집을 확인하여 정상 변경으로 되돌린다. 사용자 수정·검토/운영 이력을 삭제하여 롤백하지 않는다.

모듈별 정본 도입 준비와 기존 구현 검증 연결은 S08B-3에서 구현한다. 이것이 이번 완료로 자동 충족된 것은 아니다. KIT-CHG-018은 major/in_progress, Kit 버전 1.0.0 유지. 실제 제품 도입·커밋·태그·릴리스 없음. KIT-DRQ-018-08에서 S08B-3만 승인 요청하며 S09/10은 시작하지 않는다.
