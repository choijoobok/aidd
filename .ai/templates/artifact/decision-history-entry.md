# 결정 이력 입력 — HIS-YYYYMMDD-NNN

> 의미 있는 분석·설계·용어·소스·범위·상태 결정을 안정 ID와 연결한다. 사람의 권한을 증명하는 문서가 아니라 나중에 이유와 영향을 복원하기 위한 기록이다.

| 항목 | 내용 |
|---|---|
| 발생 시각 | YYYY-MM-DDTHH:mm:ss.sssZ |
| 유형 | analysis / design / terminology / source / scope / status / operation / decision |
| 대상 안정 ID | REQ-###, ADR-###, CHG-### 등 |
| 연결 변경 | CHG-### 또는 없음 |
| 결정 주체 | 사람 이름, 팀, 회의체 또는 “프로젝트팀 오프라인 협의” 같은 자유문자 |
| 결정 | 무엇을 선택했는가 |
| 이유 | 왜 이 선택을 했는가 |
| 이전 상태 | 선택 전 상태 또는 대안 |
| 영향 | 영향받는 모듈·문서·사용자·운영·마이그레이션 |
| 출처 | 회의록, 이슈, 사용자 요청, 외부 근거 |
| 대체 이력 | 잘못되거나 폐기된 기존 HIS ID 또는 없음 |

현재 정본에는 현재 상태와 여전히 유효한 핵심 근거를 반영한다. 이 입력은 `record-history`로 `project/.aidd/ssot/common/HIS/ 또는 modules/<MOD>/HIS/`에 저장하며, 과거 파일은 수정하지 않고 새 이력으로 대체 관계를 남긴다. 오탈자와 단순 서식 변경은 기록하지 않는다.
