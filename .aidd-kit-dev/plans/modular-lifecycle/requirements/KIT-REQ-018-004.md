# KIT-REQ-018-004 — 개별·관계·전체 업무 정합성 검토

- 출처: 사용자 의도 — 요구사항끼리 상세 모순 검토 / 계획 목표 3~4, 9
- 목적: 항목별 문장이 맞아도 업무 연결에서 발생하는 누락·충돌을 발견한다.
- 대상·트리거: 요구사항 검토 준비, 새 요구 추가, 기존 요구 의미 변경.

## 요구 동작

- 개별 요구의 명확성, 관련 요구끼리의 규칙/상태/데이터 일치, 범위 전체의 업무 시작→종료 연결을 검토한다.
- 비교 대상 ID·개정본, 검토 관점, 발견한 모순/중복/누락, 해결 결정과 잔여 불확실성을 남긴다. 검토했다는 불리언만으로 완료를 인정하지 않는다.
- 공통 규칙과 용어·데이터 정의는 소유 정본을 참조한다. 동일 용어의 다른 의미, 같은 조건의 상충 결과, 삭제/보존·권한/상태·품질 목표 충돌을 검토한다.
- 도구는 참조 누락·명시적 미해결 충돌·기록 유효성을 검사한다. AI는 의미 충돌 후보를 설명하고 실제 선택이 필요한 항목은 사용자 결정으로 해결한다.
- 관련 내용이 바뀌면 해당 검토의 재사용 가능 여부를 확인한다. 확인하지 않은 의미적 모순이 전혀 없다고 보증하지 않는다.

## 범위·관계

- 포함: 전체 범위의 최초 검토와 변경 영향에 따른 재검토.
- 제외: 모든 요구사항 쌍의 무조건 비교, 문장의 모든 단어를 용어집에 등록하는 강제.
- 관계: 003, 005~007, 014, 021.

## 인수 기준

- AC-004-1: 주문 취소와 환불 처리 사이의 연결 누락을 발견하면 해당 요구와 미결 항목을 연결하고 해결 전 준비 완료로 표시하지 않는다.
- AC-004-2: 검토 범위·개정본·결과 없는 완료 표시는 거부한다. 후보만으로 사용자 정책을 자동 수정하지 않는다.
- AC-004-3: 무관한 요구 추가 시 기존 검토는 보존하고, 같은 규칙을 변경하면 관련 검토를 재검토 대상으로 식별한다.
- 검증 연결: ACC-004, E2E-001. 의미 발견 품질은 사람이 결과를 확인하는 평가를 포함한다.
