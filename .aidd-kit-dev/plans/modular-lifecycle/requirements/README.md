# 개편 요구사항 — S02 사용자 검토본

- 묶음: `KIT-RBL-018-S02-01` / 개정 1
- 상태: `review_ready` — 작성·자체 검토 완료 후 사용자 검토 대기. S02 착수 승인은 이 내용의 승인이 아니다.
- 대상: KIT-CHG-018의 모듈별 생애주기 개편 전체 범위
- 정본 역할: Kit 관리용 요구사항 초안. 승인 뒤 S03 설계와 portable 명세 정비의 입력으로 사용한다. 현재 구현된 동작이나 제품 프로젝트 정본으로 간주하지 않는다.
- 세부 요구: `KIT-REQ-018-001`~`021`. 기존 프로젝트의 REQ나 새 portable 스키마를 생성한 것이 아니다.
- 공통 독자: Kit 사용자, 프로젝트 수행팀, AI와 Kit 관리자
- 공통 우선순위: 모두 이번 개편의 필수 요구. 개별 항목에 명시한 적용 조건은 지원 범위를 좁혀 승인 조건을 우회하는 수단이 아니다.
- 모든 상세 문서는 개정 1의 검토 대상이며, 사용자 결정 귀속은 [진행 상태](../status.json)에서 관리한다.

## 읽는 순서

1. 아래 목록으로 전체 범위를 확인한다.
2. 상세 항목에서 동작·범위·관계·인수 기준을 검토한다.
3. [인수 시나리오](acceptance.md)에서 정상·부정·경계 입력과 관찰할 결과를 확인한다.
4. [정합성 검토와 설계 인계](review.md)에서 충돌 조정, 한계, S03에서 결정할 사항을 확인한다.
5. [계획 포괄성](coverage.md)을 확인한다.

## 완료와 승인 해석

- S02 작업 완료는 요구사항이 검토 가능하게 작성되었다는 뜻이다. 사용자 검토 완료·설계 착수·기능 구현 완료는 각각 별개다.
- 도구는 구조·참조·판정 유효성을 검사한다. AI는 의미 검토와 후보 발견을 수행한다. 사용자만 업무 의도·범위·수용 여부를 결정한다.
- 기계 검사 통과만으로 미발견 모순이 없음을 보증하지 않는다. 검토한 대상·관점·발견·결정과 잔여 불확실성을 기록한다.
- 이 개정본의 수용과 S03 착수 여부를 함께 명시적으로 질문한다. 수정을 요청하면 요구사항 개정과 관련 검토를 S02에서 계속한다.
- 상세 구현 필드명, enum, 인덱스 위치, CLI 명령과 변환 알고리즘은 S03 설계 사항이다.
