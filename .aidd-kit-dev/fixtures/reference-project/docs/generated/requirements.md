# 요구사항 정의서

## REQ-001 — 프로젝트 정본 레코드

프레임워크는 의도, 요구사항, 설계, 결정, 위험, 작업, 테스트, 릴리스와 유지보수 이력을 기계가 읽을 수 있는 정본 레코드로 관리해야 한다.

### 근거

정규화된 하나의 정본은 서술형 산출물 사이의 불일치를 방지한다.

- 우선순위/상태: `must` / `specified`
- 모듈: MOD-GOV
- 검증: TC-001
- 출처: USER-2026-09-17

- 모든 정본 레코드는 파싱 가능하고 안정적인 ID가 있다
- 레코드 간 참조가 검증된다

### 근거

- 요구사항은 하나의 모듈 정본 조각에만 저장되고 다중 모듈 영향은 ID 링크로 유지된다
- 신규 모듈은 기존 모듈의 요구사항을 다시 쓰지 않고 카탈로그·빈 정본 조각·생성 명세를 추가할 수 있다
