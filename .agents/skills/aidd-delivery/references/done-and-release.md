# 완료와 릴리스 게이트

변경 완료란 승인된 동작이 구현되고, 연결된 테스트가 통과하며, 필수 검토가 해결되고, 문서와 운영 자산이 최신이며, 텔레메트리가 충분하고, 롤백이 신뢰할 수 있음을 뜻한다. 다중 인스턴스·비동기·외부 연동·고부하가 적용되면 로컬 단위 테스트만으로 완료할 수 없고 경쟁·중복·스레드 전환·부하·장애·복구 증거를 남긴다. 모든 예외에는 담당자, 위험과 결정이 있어야 한다.

릴리스 준비 완료에는 호환 가능한 산출물, 마이그레이션·복구 증거, 미해결 차단사항 없음, 치명적 잔여 위험 수용, 지원 담당과 고객의 출시 결정이 추가로 필요하다. 배포 성공은 성과 달성이 아니므로 출시 후 지표와 피드백 기간을 정의한다.
