# 화면 명세서 워크시트 — SCR 입력

> 독자: 화면을 설계·구현·검증하는 AI와 검토자. 이 문서는 연결된 제품 요구사항과 유즈케이스를 특정 화면의 상태·정보·행동 계약으로 구체화한다. 프레임워크·컴포넌트·함수 이름 같은 구현 선택은 프로젝트의 개발 표준과 ADR에 맡긴다. 해당하지 않는 항목은 삭제하지 말고 없음으로 기록한다.
