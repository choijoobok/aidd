# 검토 깊이 매트릭스

- C0: 집중 변경 비교, 정본 링크, 포매터·린터 또는 동등한 검사.
- C1: 인수·부정 테스트, 모듈 계약, 롤백 가능성, 문서 영향.
- C2: 모듈 횡단·데이터·인터페이스 영향, 배포 프로필과 실제 토폴로지, 트랜잭션·스레드·다중 인스턴스 경쟁, 성능·포화·장애 전파, 위협·개인정보 검토, 마이그레이션, 회귀 맵, 관측성·복구.
- C3: 모든 C2 검사와 독립 검토자, 사전 연습, 증거 보존, 명시적인 잔여 위험·출시 승인.

모든 발견사항에는 심각도, 영향 ID, 증거, 결과와 개선안을 포함한다. “발견사항 없음”은 검토한 범위와 증거가 명시되었다는 뜻이며 위험이 0이라는 뜻이 아니다.

모든 등급에서 구조화된 증거의 출처와 대상 커밋을 확인한다. C2·C3에서는 필수 게이트 실행의 기준별 판정, 양방향 증거 링크, 승인 독립성과 예외 만료를 추가로 확인한다.

승인 독립성의 구현은 협업 프로필에 따라 달라진다. 1인 프로필의 C2·C3는 구현과 분리된 AI 세션 또는 Codex·Claude 교차 검토 증거를 사용하고, 팀 프로필은 작성자 외 활성 사람 승인 최소 1건을 사용한다. AI 역할명을 여러 개 붙인 동일 실행은 독립 검토자가 여러 명인 것으로 계산하지 않는다.

여러 Git 이름·이메일을 여러 사람으로 계산하지 않는다. `IDM`에서 기존 `HUM`의 별칭인지, 별도 사람인지, 봇인지 확인한다. 미등록 신원이 있으면 C2·C3와 릴리스 검토를 차단하고, 원격 승인 독립성은 호스팅 제공자의 PR·승인·push 행위자 증거로 확인한다.

AI 플랫폼 동등성은 공통 스킬 파일, 공통 `EVS` 입력·루브릭, 플랫폼별 실제 실행 결과의 세 층으로 검토한다. 저장소 통제는 로컬 워크플로·ruleset 정합성과 원격 기본 브랜치 활성화 증거를 분리한다.
