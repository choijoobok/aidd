# 검토 깊이 매트릭스

- C0: 집중 변경 비교, 정본 링크, 포매터·린터 또는 동등한 검사.
- C1: 인수·부정 테스트, 모듈 계약, 롤백 가능성, 문서 영향.
- C2: 모듈 횡단·데이터·인터페이스 영향, 배포 프로필과 실제 토폴로지, 트랜잭션·스레드·다중 인스턴스 경쟁, 성능·포화·장애 전파, 위협·개인정보 검토, 마이그레이션, 회귀 맵, 관측성·복구.
- C3: 모든 C2 검사와 독립 검토, 사전 연습, 증거 보존, 명시적인 잔여 위험·출시 결정.

모든 발견사항에는 심각도, 영향 ID, 증거, 결과와 개선안을 포함한다. “발견사항 없음”은 검토한 범위와 증거가 명시되었다는 뜻이며 위험이 0이라는 뜻이 아니다.

모든 등급에서 구조화된 증거의 출처와 대상 커밋을 확인한다. C2·C3에서는 필수 게이트 실행의 기준별 판정, 양방향 증거 링크, 검토 독립성과 예외 만료를 추가로 확인한다.

독립성 수준은 변경 위험과 프로젝트가 정한 검토 방식에 따른다. 구현과 분리된 AI 세션, Codex·Claude 교차 검토 또는 별도 사람 검토를 사용할 수 있으며 결과를 EVD와 필요한 결정 이력에 남긴다. AI 역할명을 여러 개 붙인 동일 실행은 독립 검토가 여러 번 수행된 것으로 계산하지 않는다.

AIDD는 Git 이름·이메일이나 호스팅 계정으로 팀원 수·역할·검토 독립성을 판정하지 않는다. 신원 또는 원격 행위자 검증이 제품 요건이면 별도 보안 검토 범위에서 호스팅 제공자의 실제 증거를 사용한다.

AI 플랫폼 동등성은 공통 스킬 파일, 공통 `EVS` 입력·루브릭, 플랫폼별 실제 실행 결과의 세 층으로 검토한다. 저장소 통제는 로컬 워크플로·ruleset 정합성과 원격 기본 브랜치 활성화 증거를 분리한다.
