# 프로젝트 수행 생명주기

프로젝트 수행 생명주기는 루트 `AGENTS.md`와 `.ai/skills/`의 계약을 따른다. 제품 정본은 `project/.aidd/ssot/`, 파생 문서는 `project/docs/generated/`, 제품 소스는 `project/src/`에 둔다.

수행팀은 의도·성과·범위 합의, 요구·설계·표면 문서화, 위험 비례 게이트, 작은 구현 증분, 검증 증거, 출시·운영의 순서로 일한다. 배포된 Kit 파일도 프로젝트 상황에 맞게 바꿀 수 있지만, 변경 이유와 영향·검증 결과를 프로젝트 정본에 기록한다.

Kit 원본의 변경을 발견했다고 해서 프로젝트에 자동 적용하지 않는다. 반대로 프로젝트의 개선을 원본에 코드로 자동 반영하지 않는다. 필요한 경우 변경 정보를 검토하고 각 환경에서 별도 변경으로 구현한다.
