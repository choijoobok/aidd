AI 주도 개발·운영 프레임워크

AIDD Kit은 고객과 AI가 소프트웨어 제품의 의도부터 운영·개선까지 함께 관리하도록 돕는 재사용 가능한 개발·운영 키트다.

프로젝트 개요

제품 정본, AI 공통 규약, 자동 생성 문서, 검증 증거와 협업 통제를 하나의 저장소 흐름으로 연결한다.

목적과 의도

문서·코드·테스트·운영 기록이 서로 분리되어 의도를 잃지 않도록, 고객의 결정과 검증 가능한 증거를 제품 생애주기 전체에 연결한다.

주요 기능

  • 모듈별 요구사항·진척·의존성을 분리해 관리한다.
  • Codex와 Claude가 같은 공통 규약·스킬·훅 계약을 따른다.
  • 정본에서 요구사항, 설계, 사용자·운영 가이드와 HTML 프로젝트 홈을 생성한다.
  • 변경·병합·재검토·테스트·승인을 추적 가능한 ID와 증거로 연결한다.
  • 프로젝트별 기술 스택과 UI·공통 컴포넌트 기준을 고객과 합의해 발전시킨다.
