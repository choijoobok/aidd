# 브리핑 뷰

- 경영진: 성과 상태, 단계, 협업 프로필·미등록 신원, 배포·기술 게이트와 릴리스 신뢰도, 차단사항, 치명적 위험, 기록된 경우 예산·일정 신호, 필요한 결정, 다음 이정표.
- 모듈: 목적, 상태, 배포 프로필·토폴로지, `WRK` 작업 상태, `IFC` 계약, `DPN` 의존성, 요구사항·테스트 수, 진행 변경, 적용 설계 위험, 차단된 인터페이스, 다음 작업.
- 상세: 영향받는 각 요구사항·변경·테스트·마일스톤·작업·인터페이스·의존성·배포 가정·설계 위험·게이트 실행·승인·증거·예외·미결사항, 담당자, 상태와 정확한 차단 원인.

`not_run`, `unknown`, `failed`를 하나의 상태로 합치지 않는다. 계획된 작업을 진척 증거로 표현하지 않는다.

AI 평가에서는 Codex와 Claude의 각 실행 슬롯을 표시하고, 저장소 보호에서는 로컬 구성과 원격 활성화를 분리한다.

협업 신원에서는 등록된 Git 작성자·커미터, 미등록 신원과 사람·봇 분류 상태를 표시한다. Git 이력만 확인했으면 실제 원격 push·PR 행위자까지 검증했다고 표현하지 않는다.
