# S05 — 모듈 주기·요구·검토·설계 진입

APR-004 승인 범위로 완료하고 S06으로 진행한다.

- CHG 전체 범위, REQ/NFR 상세 적용성·AC, 분석 후보, 미배정/경쟁 변경, 범위 축소를 판정한다.
- 현재 해시와 입력 digest의 RVW만 현재 승인으로 인정한다. 부분/늦은 응답과 실제 사용자 결정을 구분한다.
- BSL 고정과 원문 snapshot, RVW/HIS/OI/DRQ 원자 저장, read-only 설계 검사와 명시적 GTR 기록을 연결했다.
- 운영 사실과 새로운 주기 판정은 별개다. 무관한 B 모듈 질문이 A를 차단하지 않는다.

## 검증

요구 준비도 6/6, 실제 파일·기준선·질문 종료·늦은 응답·CLI·GTR 연결 1/1, 저장 회귀 5/5 통과. provider 동기화와 Kit check/smoke 통과. 입력 fixture의 사용자 결정은 합성 시험 데이터이며 실제 제품 요구 승인으로 간주하지 않는다.

## 재개

S06: 기능·화면 설계/목업·작업 단위 개발·typed 영향·선택적 재작업·실통합 증거를 연결한다. S07 산출물과 S08 전체 provider 수행·S09 전환·S10 최종 인수는 아직 완료가 아니다.
