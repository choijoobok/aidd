# 애플리케이션 소스

이 폴더에는 제품의 실제 구현을 둔다. AIDD Kit은 특정 기술이나 소스 레이아웃을 미리 강제하지 않는다.

- 모듈형 단일 애플리케이션: `app/` 또는 `modules/<module>/`
- 웹·API 분리: `frontend/`, `backend/`
- 독립 서비스: `services/<service>/`

아키텍처와 기술 기준선을 합의하기 전에는 기존 소스를 자동으로 옮기거나 새 구조를 확정하지 않는다. 확정 뒤 소스 경로와 모듈 ID의 대응을 `project/.aidd/ssot/` 정본에 기록한다.
