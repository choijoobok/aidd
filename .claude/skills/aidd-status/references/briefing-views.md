# 브리핑 뷰

- 경영진: 성과 상태, 단계, 배포·기술 게이트와 릴리스 신뢰도, 차단사항, 치명적 위험, 기록된 경우 예산·일정 신호, 필요한 결정, 다음 이정표.
- 모듈: 목적, 상태, 배포 프로필·토폴로지, 의존성, 요구사항·테스트 수, 진행 변경, 적용 설계 위험, 차단된 인터페이스, 다음 작업.
- 상세: 영향받는 각 요구사항·변경·테스트·배포 가정·설계 위험·미결사항, 담당자, 상태, 증거와 정확한 차단 원인.

`not_run`, `unknown`, `failed`를 하나의 상태로 합치지 않는다. 계획된 작업을 진척 증거로 표현하지 않는다.
