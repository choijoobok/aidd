# 산출물과 정본 모델

## 권위 순서

1. `project/.aidd/ssot/`에 기록한 현재 의도·요구사항·결정·변경.
2. 스키마, API 명세, 마이그레이션, 테스트, 정책 코드 같은 실행 가능한 계약.
3. `project/docs/generated/`의 사람이 읽는 자동 생성 문서.
4. 구현과 실행 환경에서 수집한 증거.

하위 계층은 상위 계층에 부합해야 한다. 불일치는 결정 또는 변경 레코드로 해결하며 어느 한쪽을 조용히 덮어쓰지 않는다. Git은 정확한 파일 차이를 보존하고, 결정 이력은 그 차이를 선택한 이유와 영향을 설명한다.

## 프로젝트 운영과 AIDD 기록의 경계

인력, 직책, PM 위임, 작업 배정, 일정, 휴가, 승인 권한과 Git 계정 신원은 프로젝트 운영 영역이다. 팀은 회의나 별도 PM 도구에서 이를 관리한다. AIDD 정본과 실행 게이트는 특정 사람·역할·계정의 존재를 요구하지 않는다.

AIDD는 제품 실행과 산출물의 추적성에 집중한다. 중요한 분석·설계·용어·소스·범위·상태 결정은 누가 또는 어떤 협의체가, 무엇을, 왜 결정했으며 무엇에 영향을 주는지 남긴다. 여기서 결정 주체는 자유문자 기록이지 인증·권한 부여 수단이 아니다.

## 현재 상태와 결정 이력

- 현재 정본 항목에는 현재 상태와 지금도 유효한 핵심 근거를 둔다.
- `project/.aidd/ssot/history/YYYY-MM/HIS-YYYYMMDD-NNN.json`에는 중요한 결정의 시각, 유형, 대상 안정 ID, 결정 주체, 결정, 이유, 이전 상태, 영향, 출처와 대체 관계를 append-only로 기록한다.
- 장기적 아키텍처 선택은 `ADR`, 구현 범위와 검증·롤백은 `CHG`, 용어 변경은 `TCH`를 사용하며 필요한 경우 `HIS`가 이 ID들을 연결한다.
- 오탈자, 서식 정리, 의미 없는 기계적 변경은 별도 이력을 만들지 않는다.
- 과거를 정정할 때 기존 HIS를 수정하지 않고 새 HIS의 `supersedes`로 연결한다.

## 안정적인 식별자

주요 접두사는 다음과 같다. `OUT` 성과, `REQ` 요구사항, `MOD` 모듈, `WRK` 작업 패키지, `IFC` 인터페이스, `DPN` 의존성, `SURF` 구현 표면, `LDP` 레거시 전환 계획, `ADR` 결정, `HIS` 결정 이력, `OI` 미결사항, `RSK` 위험, `CHG` 변경, `TC` 테스트, `REL` 릴리스, `MRG` 병합 영향, `MRC` 병합 후 재검토, `TRM` 프로젝트 용어, `TCH` 용어 변경 이력, `GTR` 게이트 실행, `GCR` 판정 기준, `EVD` 검증 증거, `SCR` 화면, `MAN` 화면 매뉴얼, `RUN` 운영 런북, `DLP` 제출 프로필이다. 제목이 바뀌어도 ID는 변경하지 않는다.

## 작성 문서와 생성 문서

- 직접 작성: `project/.aidd/ssot/**/*.json`, `project/src/`의 제품 코드·테스트·운영 설정, AIDD Kit 자체의 방법론 설명.
- 자동 생성: 요구사항, 아키텍처, 모듈, 작업 범위, 결정 이력, 용어집, 테스트·증거, 릴리스 준비도, 사용자·운영 가이드와 사이트.
- 자동 생성 파일에는 원본을 표시하고 사람이 직접 수정하지 않는다.

## 일관성 불변 조건

- 모든 요구사항은 존재하는 모듈과 테스트를 참조하고 양방향 링크가 일치한다.
- 완료된 요구사항과 작업 패키지는 통과한 검증 증거에 연결된다.
- 모든 모듈에는 구현 표면 조각이 있고, 문서가 있는 표면은 생성물이 아닌 정본 경로를 연결한다.
- `REL`은 존재하는 변경·테스트·전달 프로필을 참조하며 차단 미결사항, 실패한 필수 테스트와 수용되지 않은 치명적 위험이 있으면 준비 완료가 될 수 없다.
- `MRC` 완료에는 실제 수행 주체, 완료 시각, 결과와 필요한 증거가 있다. 수행 주체는 자유문자이며 AIDD 참여자 계정과 대조하지 않는다.
- `TCH`에는 결정 주체·시각·요약·영향·적용과 검증 결과가 있다. 특정 PM 역할이나 Git 신원을 요구하지 않는다.
- `HIS` ID의 날짜는 `occurred_at` 날짜와 일치하고, 대상·변경·대체 이력은 존재하는 안정 ID를 참조한다.
- 신규 모듈과 이력 기록은 저장소 쓰기 잠금과 고유 임시 파일을 사용하고, 다중 파일 처리 실패 시 부분 결과를 롤백한다.
- Codex와 Claude 스킬 어댑터는 `.ai/skills/` 정본과 바이트 단위로 동일하다.
- `AGENTS.md`는 공통 AI 수행 계약의 단일 정본이고 `CLAUDE.md`는 이를 import한 뒤 provider 전용 연결만 추가한다.

`node .ai/tools/aidd.mjs validate`는 기계적으로 확인 가능한 조건을 검사한다. 의미 품질은 프로젝트가 정한 검토 방식으로 확인한다.
