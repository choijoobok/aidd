첫 AIDD 파일럿은 신규 구축 제품과 기존 시스템의 단일 모듈 중 어느 쪽으로 진행할까요?

1. 신규 구축 제품
2. 기존 시스템의 단일 모듈
3. 선정을 보류하고 평가 기준부터 결정

- 권장안: 기존 시스템의 경계가 작은 단일 모듈 — 현재 동작 기준선과 문서 현행화 효과를 제한된 범위에서 함께 검증할 수 있다.
- 답하지 않을 때: 실제 제품에서 방법론을 검증할 대상과 다음 실행 범위를 확정할 수 없다.
